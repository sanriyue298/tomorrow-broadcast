# WebGAL modifications

This website uses WebGAL 4.6.6 under MPL-2.0. Unmodified upstream source is available at https://github.com/OpenWebGAL/WebGAL . This directory provides the modified engine files corresponding to this website: the title, reading toolbar, theme, font declarations, entry page, and Escape behavior. The development-only QA module referenced behind import.meta.env.DEV is not part of the distributed production program.

These files are supplied for license compliance. The separate editable game project, development dependencies and original image-generation assets are not included in this website repository.
