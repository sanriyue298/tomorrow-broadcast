# EMBER / 移动废土城

安卓浏览器横屏优先的原创策略生存游戏。无框架、无第三方游戏源码、无远程运行时依赖。

## 运行

在 `dist` 目录运行 `python -m http.server 8772`，打开 `http://localhost:8772`。也可使用任意静态文件服务器。

## 游玩

- 三种起始底盘，五个航区、每区两条路线，十一种模块。
- 点选设备后点空位安装；向上拖动设备卡片可直接安装。拖动车体内设备可移动。
- 点选已有设备升级，最高三级；生产、火力、耐久随等级提升。
- 开启供弹网络检查工坊与武器的连通关系。无人机独立于弹药。
- 点选敌人集火。Q 齐射、E 应急护盾、R 抢修；空格暂停。所有操作有触屏按钮。
- 途中遭遇和战后技术选择会暂停模拟。终点必须击败铁墓，超时失败。
- 当前浏览器每五秒自动保存，退出页面时保存，后台自动暂停。存档不跨设备，旧版 v0.1 存档保留但不会导入 v0.2。

## 实现

- `dist/engine.js`：独立、可复现的游戏模拟，固定世界坐标。
- `dist/renderer.js`：原创程序绘制场景、机械设备、预警与粒子。
- `dist/game.js`：触控输入、界面、存档、可选合成音效。
- `dist/style.css`：固定游戏布局、手机横屏与备用竖屏模式。
- `dist/manifest.webmanifest`：独立窗口元数据；未实现离线缓存，不宣称离线可用。

## 验证

运行 `node check-game.cjs`。覆盖供弹、经济、升级、装甲/护盾、技能、遭遇、结束条件与存档确定性。30 个种子的整局模拟使用真实购买和技能操作，没有额外资源或免费治疗。自动模拟用于发现规则缺陷，不能替代真实手机手感和性能测试。

音效只在用户主动开启后启动。不使用跟踪、外部字体或外部素材。浏览器对全屏和方向锁的支持不同，失败时保留普通横屏模式。
